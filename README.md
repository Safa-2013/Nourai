# Nour AI Studio v3

Echte Gemini-KI für Vercel mit Chat, Bildgenerierung, Veo-Video und Website-Generator. Dazu kommen ein einfacher Canva-ähnlicher Bildeditor, ein CapCut-ähnlicher Videoeditor und ein Website-Editor.
